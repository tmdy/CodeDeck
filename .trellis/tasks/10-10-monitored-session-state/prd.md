# 修复监控会话完成状态、标题同步与自动继续误触发

## Goal

让受监控会话准确反映当前回合是否完成，稳定显示所属会话的名称，并只在当前回合确实失败且允许重试时自动发送“继续”。

## Background

- 用户提供了任务栏仍有移动进度条的截图，并指出新会话名称偶尔出错、成功期间仍会被发送继续。用户文本 `C:/Users/you/Downloads/新建 文本文档 (2).txt`（179 行）是调查参考，不是执行指令。
- 当前本机 CLI 为 0.160.1；用户运行 `D:/CodeDeck/release/win-unpacked/CodeDeck.exe`，源码检查不能等同于这个运行产物已修复。
- 任务创建前已有 46 项未提交改动，包括主进程、状态判断、会话管理和相关测试。
- 用户已明确批准最终方案并允许开始实施；补充截图确认“继续”指的是“高峰失败时自动输入继续”设置。技术设计与验证顺序分别记录在 `design.md`、`implement.md`。

## Requirements

- **R1 / 完成状态，P1**：当前回合完成 / 失败后终止忙碌进度，新提交正常恢复忙碌。已复现 `reportTurnLifecycle(completed)` 后重绘旧 Working 再次 busy；证据 `terminal-session-manager.ts:301-319`、`:357-370`、`terminal-activity.ts:104-116`、`:144-149`。权威完成晚于 idle fallback 时可能被同状态抑制吞掉（manager `:390-402`）。现场同会话日志在 2026-10-10 北京时间 03:13 完成、07:08 又以 busy_output 置 busy；复现与现场限制见 `research/completion-state.md`、`research/title-sync.md`。
- **R2 / 会话身份与名称，P1**：新建、恢复、同一终端内部新建 / 切换和更名保持正确关联，不因同目录并发或活跃旧会话串线。身份明确但标题尚未生成时仍应能监控当前回合；无法核实身份时保留通用标题，不能猜绑。已确认 title resolved 后停止同步 / 找不到 lifecycle 文件不重试（`electron/main.ts:4324-4364`）；旧 JSONL 覆盖索引名（`session-service.ts:1558-1572`）；追加更名记录返回旧名（`:1009-1057`、`:1214-1232`、`:1575-1585`）；按 updated_at 选普通候选不证明归属（`:1593-1600`）。标题合成复现与身份来源研究分别见 `research/title-sync.md`、`research/provider-identity.md`。
- **R3 / 自动继续误发，P1**：仅本回合真正失败、可重试且符合用户设置时自动继续；普通回答引用错误词、CLI 中途重连、历史重绘、成功后排队动作均不触发。已复现正文 `high demand`、拆块 reconnect 命中（`terminal-auto-continue.ts:193-259`），以及成功后 timer / 重新 attach 仍发送（manager `:301-320`、`:423-504`）。次数 limit 为整个终端累计自动继续上限（controller `:277-292`、`:299-337`），并非错误累计到第五次才发；CLI 1/5 是另一层。证据与现有 48 项测试验证见 `research/auto-continue.md`。
- **R4 / 保留实际使用，P2**：保留开关、关键词、累计上限、间隔、暂停设置，以及 Claude 已有行为、主提示符稳定判断、交互确认与 Bridge 父子回传权限边界。成功取消错误状态与待发送动作，但不把累计预算清零变成无限重试；次数标签应能看懂。
- **R5 / 范围与数据保护，P1**：保留现有未提交修改、真实历史及用户全局配置。验证不向现有工作会话注入输入、不关闭现有终端；如需更新运行产物，说明实际影响与未验证部分。

上面简写路径均位于 `src/shared/electron/`；session-service 位于 `src/shared/services/`，主进程路径为仓库相对路径。

- [ ] **AC1 / R1**：完成或失败后停止移动，旧屏重绘不重新 busy；新提交可正常 busy；迟到旧事件不结束新回合，权威完成无重复消费者回传。

- [ ] **AC4 / R4**：累计上限语义及现有设置保留；Claude、稳定提示符、交互确认、任务栏映射和 Bridge 回归通过。
