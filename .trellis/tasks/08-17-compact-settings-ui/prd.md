# 精简 Profile 渠道与全局设置界面

## Goal

精简 Profile 渠道、站点后台会话/签到和全局设置界面的说明文字与宽屏布局，保留现有业务行为。

## Requirements

- 当前渠道选择器与新增、重命名、删除操作组成紧凑输入组。
- 渠道健康区域只显示检测按钮和紧凑状态徽章；详细来源、时间、延迟和连续成功次数仅通过悬浮提示提供。
- 站点后台会话移除浏览器安全说明和底层接口元信息。
- 浏览器账号选择、登录状态和登录操作保持在同一紧凑区域；PAT / Access Token 保留为折叠项。
- 退出登录和删除会话保持并排的紧凑按钮。
- 签到成功状态、奖励和时间合并为一个紧凑徽章，详细信息通过悬浮提示提供；失败诊断与人工验证操作仍可见。
- 全局设置内容限制在约 680px 宽度，使用带分隔线的标准 Form Row；复选框紧贴标签。
- 全局代理 placeholder 简化为示例地址。
- 不改变健康检测、余额检测、签到、浏览器登录或凭证保存逻辑。
- 不引入新依赖或新的通用组件层。

## Acceptance Criteria

- [x] 指定冗余文案和底层 API 路径不再直接显示。
- [x] 三处界面在宽屏和窄屏下均保持紧凑且无明显溢出。
- [x] 相关组件测试与 TypeScript 类型检查通过。

## Notes

- 保留现有可访问名称和必要的失败提示。
